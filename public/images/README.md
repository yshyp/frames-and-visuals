# Photography Assets Directory
This directory hosts your local photography files organized by album/chapter folder.

Structure:
- `/public/images/wildlife/`
- `/public/images/macro/`
- `/public/images/nature/`
- `/public/images/travel/`
- `/public/images/stories/`
- `/public/images/<custom-album>/`

Any images placed in `/public/images/...` can be directly referenced as `/images/...` in your code and photobook.
